# دوري · الموقع التسويقي

صفحة هبوط عربية لمنتج «دوري»، نظام الانتظار الرقمي للمحلات الصغيرة في السعودية.

- `site/dawri.html`: محتوى الصفحة (المصدر الذي يُعدَّل)
- `build.sh`: يغلّف المحتوى في `site/index.html` كمستند كامل
- `netlify.toml`: النشر على Netlify، ونموذج «اطلب التجربة» يعمل عبر Netlify Forms

```bash
./build.sh && npx serve site
```
