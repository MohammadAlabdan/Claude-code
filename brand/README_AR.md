# هوية «جاي» — المرجع النهائي

**الشعار المعتمد:** تذكرتان مائلتان (الأمامية خضراء بحرف «ج» ذهبي، والخلفية إطار ذهبي)، وبجانبها كلمة «جاي» و JAY والشعار النصي.

**الشعار النصي:** دورك جاي.. وأنت مرتاح

## الألوان
| الاسم | الكود | الاستخدام |
|---|---|---|
| أخضر جاي | `#0E3B3A` | اللون الأساسي، الخلفيات الداكنة، الأزرار |
| ذهبي | `#C9A66B` | اللمسات، الكلمات المميزة، الأرقام |
| كريمي | `#F3EDE2` | الخلفيات الفاتحة، النص على الأخضر |
| ورقي | `#F7F3EC` | خلفية الصفحات |
| ذهبي غامق | `#8E6A2C` | نص ذهبي على خلفية فاتحة (للوضوح) |

## الخطوط
- **Readex Pro** (500 / 600 / 700): العناوين والشعار.
- **IBM Plex Sans Arabic**: النصوص الطويلة.

## الملفات
| الملف | متى تستخدمه |
|---|---|
| `jay-logo.svg` | الشعار الأصلي (مربع) |
| `jay-logo-horizontal.svg` / `-on-dark.svg` | الشعار الكامل مع الشعار النصي: رأس الموقع، الملصقات، العروض |
| `jay-logo-compact.svg` / `-on-dark.svg` | بدون الشعار النصي: الأماكن الصغيرة |
| `jay-mark.svg` / `-on-dark.svg` | التذكرة فقط: أيقونة التطبيق، صورة الحساب |
| `png/` | نسخ PNG عالية الدقة بخلفية شفافة أو خضراء |
| `social/` | قوالب جاهزة لإكس وانستقرام وتيك توك، وخلفيات فاضية بالهوية |

النصوص داخل ملفات SVG محوّلة إلى أشكال، فيظهر الشعار صحيحاً على أي جهاز حتى بدون الخط.

## استوديو المنشورات
- الرابط: https://jay-live.netlify.app/studio/
- اختر المقاس (منشور انستقرام، مربع، ستوري وريلز وتيك توك، منشور إكس، غلاف إكس، صورة الحساب)، والقالب (إعلان، نصيحة، رأي عميل، رقم، خطوات، خلفية فاضية)، والألوان، ثم اكتب المحتوى ونزّل الصورة.

## قواعد سريعة
- لا تغيّر ألوان الشعار، ولا تمدّه، ولا تضع الشعار الأخضر على خلفية خضراء (استخدم نسخة `on-dark`).
- اترك مسافة حول الشعار بعرض التذكرة الصغيرة على الأقل.
