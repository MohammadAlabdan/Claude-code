# تشغيل «دوري» على Netlify (قاعدة بيانات كاملة)

النسخة الحيّة: **https://dawri-live.netlify.app**

## ماذا يعمل على Netlify
| الجزء | على Netlify |
|---|---|
| الواجهة (الزبون، الموظف، صاحب المحل) | ملفات ثابتة من `dawri/web` |
| قاعدة البيانات | Netlify Database (PostgreSQL)، بنفس ملفات `supabase/migrations` |
| منطق الخادم | Netlify Functions، بنفس كود `supabase/functions` عبر طبقة `_shared/pg.ts` |
| دخول صاحب المحل | كلمة مرور مشفّرة في القاعدة + رمز دخول موقّع لمدة ١٤ يوماً (`/api/auth`) |
| تحديث الشاشات | تحديث تلقائي كل ٤ ثوانٍ (بدل البث المباشر في Supabase) |
| صور صفحة المحل | Netlify Blobs (`/api/photo`) |
| المهام المجدولة | دالتان مجدولتان: الصيانة كل ١٥ دقيقة، وملخص المساء |
| المفاتيح السرية | تُولَّد داخل قاعدة البيانات تلقائياً (جدول `app_secrets`)، لا يراها أحد |

## النشر من جديد
```bash
node dawri/deploy/netlify/assemble.mjs /tmp/dawri-netlify
```
ثم انشر المجلد الناتج على مشروع Netlify (من لوحة Netlify أو أداة Netlify). عند كل نشر، يطبّق Netlify ملفات قاعدة البيانات الجديدة بالترتيب.

## قواعد مهمة
- **لا تعدّل ولا تحذف** أي ملف في `supabase/migrations` بعد نشره. أي تغيير يكون بملف جديد تاريخه أحدث.
- `--no-seed` يبني نسخة بدون المحلات التجريبية (للإطلاق التجاري).
- لتفعيل الذكاء الاصطناعي («اكتب لي بإحساس»، و«صوّر قائمتك»، ومساعد الأسئلة): أضف `ANTHROPIC_API_KEY` في إعدادات المشروع على Netlify ← Environment variables (نطاق Functions)، ثم أعد النشر.
- `SITE_URL` مضبوط على عنوان الموقع، ويُستخدم في روابط ربط أجهزة الموظفين.
